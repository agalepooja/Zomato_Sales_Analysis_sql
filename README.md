#  Zomato Sales Analysis (SQL Project)

##  Project Overview
This project contains **16 real-world business questions** solved using a **Zomato-style food delivery database**.  
As a **fresher data analyst**, this project was built to practice **advanced SQL concepts** and analyze real-life food delivery operations involving **customers, restaurants, delivery partners, orders, and payments**.

The project demonstrates strong analytical thinking and the ability to convert raw transactional data into meaningful business insights.



##  Objectives
● Strengthen advanced SQL skills through real-world scenarios  
● Analyze food delivery operations and customer behavior  
● Apply analytical SQL to solve business-driven questions  
● Showcase SQL expertise for entry-level data analyst roles  


##  Skills & Concepts Used
● SQL (MySQL / SQL Server compatible)  
● SELECT statements  
● JOINs (INNER JOIN, LEFT JOIN)  
● Aggregate functions (COUNT, SUM, AVG)  
● Subqueries  
● Window functions (RANK, OVER, PARTITION BY)  
● CTEs (WITH clause)  
● Business logic and data analysis  



##  Key Analyses in This Project
● Top 3 customers with the highest number of orders  
● Restaurant with the highest average rating  
● Orders delivered within 30 minutes  
● Total revenue generated by each food item  
● Second highest revenue-generating restaurant  
● Top 5 most popular food items by quantity sold  
● Top 3 delivery partners by average rating  
● Month with the highest number of orders  
● Average order value per customer  
● Most frequent customer for each restaurant (CTE + RANK)  
● Total orders placed on weekends  
● Average delivery time: Weekday vs Weekend  
● Top 5 most expensive food items  
● Restaurant with the most diverse menu  
● Total revenue by payment type  
● Least revenue food item (ordered at least 10 times)
